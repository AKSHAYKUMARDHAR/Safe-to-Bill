Safe to Bill?

Checks whether an urgent care visit note supports the E/M level being billed, before the claim goes out. An LLM extracts the medical decision making elements, each with an exact quote; code verifies every quote and applies the AMA table; two independent readings must agree, or the claim is held for a coder. Below is every held-out note from the release runs: the decision, the quotes it rests on (highlighted in the note), and the answer key.
